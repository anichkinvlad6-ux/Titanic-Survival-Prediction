# Titanic Survival Prediction

## О проекте

Titanic Survival Prediction — приложение на Python для прогнозирования выживаемости пассажиров RMS Titanic с использованием искусственной нейронной сети.

Программа позволяет ввести основные данные пассажира и получить вероятность его выживания или гибели. После получения прогноза приложение передаёт результат локальной языковой модели Qwen 2.5 7B для дополнительного текстового объяснения.

## Основные возможности

- Прогнозирование выживаемости пассажира.
- Расчёт вероятности выживания и гибели.
- Графический интерфейс в стиле пассажирского билета Titanic.
- Отображение точности модели.
- Отображение архитектуры нейронной сети.
- Анализ результата с помощью Qwen 2.5 7B.
- Локальная работа языковой модели через Ollama.

## Нейронная сеть

Для прогнозирования используется многослойный перцептрон MLPClassifier из библиотеки Scikit-learn.

Архитектура нейронной сети:

7 входных признаков → 32 нейрона → 16 нейронов → 2 выходных класса

Выходные классы:

- 0 — пассажир погиб.
- 1 — пассажир выжил.

Точность модели на тестовой выборке составляет 78,21%.

Для получения вероятностей используется метод predict_proba(), а для определения итогового класса — predict().

## Используемые признаки

Для прогнозирования используются следующие признаки:

- Pclass — класс пассажира.
- Sex — пол.
- Age — возраст.
- SibSp — количество братьев, сестёр и супругов.
- Parch — количество родителей и детей.
- Fare — стоимость билета.
- Embarked — порт посадки.

Целевая переменная:

- 0 — пассажир погиб.
- 1 — пассажир выжил.

Перед обучением модели данные обрабатываются с помощью Pandas. Категориальные признаки преобразуются в числовой формат, пропущенные значения заполняются медианой, а признаки стандартизируются с помощью StandardScaler.

## Qwen 2.5 7B

В проект интегрирована локальная языковая модель Qwen 2.5 7B, работающая через Ollama.

Qwen не выполняет само прогнозирование.

Сначала нейронная сеть рассчитывает вероятность выживания и вероятность гибели пассажира. После этого результат передаётся Qwen, который формирует краткое объяснение прогноза и указывает основные факторы, повлиявшие на результат.

## Графический интерфейс

Графический интерфейс выполнен в стилистике пассажирского билета RMS Titanic.

В интерфейсе отображаются:

- данные пассажира;
- вероятность выживания;
- вероятность гибели;
- итоговый прогноз;
- точность нейронной сети;
- архитектура модели;
- объяснение результата от Qwen.

## Используемые библиотеки

- math — математические операции.
- tkinter — создание графического интерфейса.
- tkinter.font — работа со шрифтами.
- customtkinter — элементы графического интерфейса.
- PIL (Pillow) — работа с изображениями.
- os — работа с файлами и путями.
- pandas — обработка и анализ данных.
- threading — выполнение задач в отдельных потоках.
- scikit-learn — машинное обучение.
- ollama — взаимодействие с локальной моделью Qwen.

Основные компоненты Scikit-learn:

- train_test_split — разделение данных на обучающую и тестовую выборки.
- StandardScaler — стандартизация признаков.
- MLPClassifier — многослойная нейронная сеть.
- accuracy_score — расчёт точности модели.

## Установка

Для установки необходимых библиотек используется команда:

pip install pandas scikit-learn customtkinter pillow ollama

Для работы Qwen необходимо установить Ollama и загрузить модель:

ollama pull qwen2.5:7b

## Запуск

После установки библиотек и модели приложение запускается командой:

python gui.py
